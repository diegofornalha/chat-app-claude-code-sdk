`404` - Not Found\n- `429` - Too Many Requests (rate limit)\n- `500` - Internal Server Error\n- `503` - Service Unavailable (component disabled)\n\n### Error Response Format\n\n```json\n{\n  \"success\": false,\n  \"error\": \"Error description\",\n  \"code\": \"ERROR_CODE\",\n  \"details\": {\n    \"field\": \"validation error details\"\n  },\n  \"timestamp\": 1692345600000\n}\n```\n\n## Rate Limiting\n\n### Default Limits\n- **General API**: 100 requests per minute\n- **Task Execution**: 20 requests per minute\n- **Telemetry Events**: 500 events per minute\n- **WebSocket Connections**: 10 concurrent per IP\n\n### Headers\n```\nX-RateLimit-Limit: 100\nX-RateLimit-Remaining: 95\nX-RateLimit-Reset: 1692345660\n```\n\n## Authentication\n\n### API Key\n```\nAuthorization:
